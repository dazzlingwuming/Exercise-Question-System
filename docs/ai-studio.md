# AI 工作台：从日常讨论到继续学习

本轮把独立 AI 对话、模型连接、计算与函数作图加入现有学习空间。图片直接出现在日常输入框和历史讨论中；不建立单独的“看图学习”栏目。

## 使用

1. 打开侧栏的 **模型连接**，填写名称、API 基础地址、API Key 和模型名。接口需兼容 Chat Completions 流式协议；基础地址不含 `/chat/completions`。部分服务使用 `/v1`。本地免密服务可以留空 Key。勾选图片能力前，应核对所选模型及服务端点是否支持 `image_url`。
2. 点击 **保存并使用**。可以保存多个连接，在工作台输入框底部切换。**测试连接**会发送一条简短文本请求，只验证文本链路，不把测试成功等同于支持图片。
3. 打开 **AI 工作台**，选择引导学习、直接解答或创作整理。输入文字、粘贴截图、拖入图片均可；附件沿用上传、预览和裁剪能力。桌面 Enter 发送，Shift + Enter 换行；触屏使用发送按钮。
4. 生成过程中可停止；中断或失败会保留收到的部分内容，最后一条未完成回复可重试。讨论记录可搜索标题、置顶、重命名、归档和恢复。浏览器保存每段讨论的输入草稿，后端保存已经发送的消息。
5. **学习工具**提供数值计算和函数采样图。例如 `sqrt(144)+2^3` 得到 20，`x^2` 可以绘制曲线；滑块查看采样坐标。工具无需模型密钥，结果可带入讨论输入框，确认后再发送。
6. 完整 AI 回复下点击 **整理成题目**，打开包含原问题、原图和参考答案的编辑草稿。核对内容、补充评分标准、选择归档集合后才会保存成题。
7. Mermaid 图表支持放大与横向滚动，手机也能看清节点。**导出**保存讨论为 Markdown；图片仍引用本地学习空间中的资源，不是包含全部图片的离线打包文件。

模型连接页还收纳原有题库 AI 的任务配置，可继续分别指定讲题、图片理解、评分和题目生成模型。工作台连接与这组任务配置各自保存，便于在自由讨论中试用模型，同时保留原有题库任务的选择。

## 实现与边界

- 新增 `studio_conversations` 和 `studio_messages` 两张表，启动时创建，不重建原题库。密钥仅在当前浏览器配置及本次后端转发请求中使用，不存入对话表；新连接不会借用后端 DeepSeek 环境密钥发送到其他地址。
- 使用可取消的异步 HTTP 流。数据库原子领取同一讨论的生成任务，避免两个窗口重复生成；成功、失败、停止均释放任务。进程退出留下的任务在 4 分钟后恢复为可重试状态，单次请求最长 3 分钟。
- 每段讨论最多 100 轮；模型上下文最多最近 10 轮、约 60,000 字符、6 张不同图片、合计 20 MiB。按整轮裁切，界面提示历史上下文被裁切；保存的完整记录不因此删除。单条输入最多 20,000 字符，回复最多 64,000 字符。
- 切换到纯文本模型时，如选取的上下文仍含图，请求会明确拒绝，提示选择图片模型或新开纯文本讨论。历史图片不会被悄悄忽略。
- 数学工具仅解释白名单算术语法，不运行 Python 或 `eval`。限制长度、节点数、嵌套深度、指数与数值范围。结果为浮点近似值，函数图是 401 点采样，不等同于符号证明；图中可能裁去极端纵轴值，坐标查看保留原始采样数据。
- AI 可以输出公式和 Mermaid 图解；工作台未接入联网浏览、代码运行、位图生成或 3D 建模，不会提示用户这些工具已经被执行。
- 长对话分批渲染消息，正文复用现有 Markdown/KaTeX/Mermaid 组件；流式正文先使用轻量文本显示，完成后渲染图解。等待其他窗口生成时只轮询轻量状态，完成后才重新获取正文。Mermaid 的临时测量容器脱离文档流，避免多张图绘制时推动输入框。
- 补修连续提交时系统时钟不递增导致的顺序问题：同一道题的提交时间保持递增，恢复作答不再依赖随机 UUID 排序；工作台同样保证消息顺序。
